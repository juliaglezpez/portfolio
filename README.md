# Archivo_01

Portfolio digital desarrollado para la asignatura **Tecnología de Diseño para Internet**.

## Descripción

Archivo_01 es un portfolio web que reúne una selección de proyectos de diseño gráfico, diseño de producto y diseño de interiores desarrollados durante la carrera.

La web está organizada en tres categorías principales y permite acceder a páginas individuales para cada proyecto, ofreciendo una navegación clara y una presentación visual coherente con la identidad del portfolio.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- Bootstrap

## Funcionalidades implementadas

- Diseño responsive para móvil, tablet y escritorio.
- Navegación multipágina.
- Filtrado dinámico de proyectos mediante JavaScript.
- Validación de formulario de contacto.
- Animaciones al scroll mediante IntersectionObserver.
- Optimización SEO básica mediante metaetiquetas.
- Uso de favicon personalizado.
